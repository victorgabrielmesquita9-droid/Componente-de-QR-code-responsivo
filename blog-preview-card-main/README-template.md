Captura de tela

Mostrar Imagem

Adicione uma captura de tela da sua solução. A forma mais fácil é usar o Firefox para visualizar o projeto, clicar com o botão direito na página e selecionar "Fazer uma captura de tela". Você pode escolher a página inteira ou uma captura recortada, dependendo do tamanho da página. Se ela for muito longa, talvez seja melhor recortar.

Como alternativa, você pode usar uma ferramenta como o FireShot para tirar a captura. O FireShot tem uma opção gratuita, então você não precisa comprar nada.

Depois, corte, otimize ou edite a imagem como preferir, adicione-a ao projeto e atualize o caminho do arquivo na imagem acima.

Observação: apague esta observação e os parágrafos acima quando adicionar sua captura de tela. Se preferir não adicionar uma captura, fique à vontade para remover esta seção inteira.
