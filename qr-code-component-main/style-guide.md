# Guia de Estilo Front-end

## Layout

Os designs foram criados nas seguintes larguras:

- Mobile: 375px
- Desktop: 1440px

> 💡 Estes são apenas os tamanhos do design. Garanta que o conteúdo seja responsivo e atenda aos requisitos da WCAG testando toda a variedade de tamanhos de tela, de 320px até telas grandes.

## Cores

- Branco: hsl(0, 0%, 100%)

- Slate 300: hsl(212, 45%, 89%)
- Slate 500: hsl(216, 15%, 48%)
- Slate 900: hsl(218, 44%, 22%)
